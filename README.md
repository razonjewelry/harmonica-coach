# Harmonica Coach

אפליקציית לימוד מפוחית דיאטונית C (10 חורים), בעברית RTL. בלי שרת, בלי משתמשים ובלי API בתשלום.

## הרצה במחשב

```bash
npm install
npm run dev      # פיתוח
npm test         # בדיקות אוטומטיות
npm run build    # בניית Production + PWA (תיקיית dist)
npm run preview  # הרצת הבנייה המוכנה
```

## בדיקה ב-Android Chrome

המיקרופון והתקנת PWA דורשים כתובת **https** (או localhost).

1. העלה את תיקיית `dist` לאחסון סטטי עם https (למשל GitHub Pages או Netlify Drop). הבנייה משתמשת בנתיבים יחסיים, ולכן היא עובדת גם מתת-תיקייה.
2. פתח את הכתובת ב-Chrome בטלפון.
3. בלשונית "הגדרות": לחץ "בדיקת קול". אם אין קול עברי, התקן אחד: הגדרות Android > ניהול כללי > טקסט לדיבור.
4. לחץ "הפעל מיקרופון" ואשר הרשאה. אם סירבת בטעות: סמל המנעול בשורת הכתובת > הרשאות > מיקרופון > אפשר.
5. בלשונית "מאמן חופשי": נגן נשיפה בחור 4. אמור להופיע C5 וחור 4 מוארים. צליל ארוך ויציב מסומן "צליל יציב".
6. התקנה: תפריט Chrome (שלוש נקודות) > "התקנה" / "הוסף למסך הבית".
7. אופליין: אחרי טעינה ראשונה, העבר את הטלפון למצב טיסה ופתח את האפליקציה מהאייקון. היא אמורה להיפתח ולעבוד.

## טיפים לדיוק הזיהוי

- נגן בחדר שקט ובעוצמה בינונית. אוזניות עדיפות כדי שהמיקרופון לא ישמע את המורה.
- נשוף ושאף בעדינות. חור אחד בכל פעם (אחרת האפליקציה לא תאשר צליל).

## מבנה

- `src/harmonica/` מיפוי תווים, זיהוי גובה צליל (YIN), הקראה בעברית
- `src/lessons/` נתוני שיעורים, מנגינות, התקדמות, התאמת רצפים
- `src/audio/` מיקרופון והשמעת הדגמה
- `src/components/` רכיבי ממשק
